# Unicode Launcher Provider Plugin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a complete, high-performance Unicode search and copy launcher provider plugin (`rigelyon/unicode`) for Noctalia shell with ~40,000 named characters and sub-millisecond search.

**Architecture:** A standalone Noctalia plugin in `unicode/` utilizing a lightweight JSON dataset (`data/unicode.json`), in-memory lazy-loaded search engine in `launcher.luau` with static category caching, debounced launcher provider (`/uni`), and configurable clipboard activation.

**Tech Stack:** Noctalia Plugin API v28 (Luau), Python 3 standard library (`unicodedata`, `json`, `unittest`), ImageMagick (`magick` for thumbnail generation).

    (0x2980, 0x29FF, "Misc Mathematical Symbols-B"),
    (0x2A00, 0x2AFF, "Supplemental Mathematical Operators"),
    (0x2B00, 0x2BFF, "Misc Symbols and Arrows"),
    (0x2E00, 0x2E7F, "Supplemental Punctuation"),
]

def get_block(cp: int) -> str:
    for start, end, name in BLOCKS:
        if start <= cp <= end:
            return name
    return "Other"

def main():
    entries = []
    for cp in range(0x110000):
        try:
            name = unicodedata.name(chr(cp))
            if not (name.startswith("CJK UNIFIED") or name.startswith("HANGUL SYLLABLE")):
                entries.append([
                    hex(cp)[2:].upper().zfill(4),
                    chr(cp),
                    name,
                    get_block(cp)
                ])
        except ValueError:
            pass

    out_dir = os.path.dirname(os.path.abspath(__file__))
    out_file = os.path.join(out_dir, "unicode.json")
    with open(out_file, "w", encoding="utf-8") as f:
        json.dump(entries, f, separators=(",", ":"), ensure_ascii=False)
    print(f"Generated {len(entries)} characters in {out_file}")

if __name__ == "__main__":
    main()

import json
import os
import unittest

DATA_FILE = os.path.join(os.path.dirname(__file__), "..", "unicode", "data", "unicode.json")

def simulate_search(data, query, max_results=30):
    query = query.strip().upper()
    if not query:
        return []

    # Check hex codepoint pattern
    is_hex = False
    hex_target = query
    if hex_target.startswith("U+"):
        hex_target = hex_target[2:]
        is_hex = True
    elif len(hex_target) >= 2 and all(c in "0123456789ABCDEF" for c in hex_target):
        is_hex = True

    results = []
    tokens = query.split()

    for item in data:
        code, char, name, cat = item
        # If hex search matches
        if is_hex and code.startswith(hex_target):
            results.append(item)
            if len(results) >= max_results:
                break
            continue

        # Multi-token name & category matching
        matched = True
        name_upper = name.upper()
        cat_upper = cat.upper()
        for token in tokens:
            if token not in name_upper and token not in cat_upper:
                matched = False
                break
        if matched:
            results.append(item)
            if len(results) >= max_results:
                break

    return results

class TestLauncherSearch(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        with open(DATA_FILE, "r", encoding="utf-8") as f:
            cls.data = json.load(f)

    def test_search_arrow_right(self):
        res = simulate_search(self.data, "arrow right")
        self.assertGreater(len(res), 0)
        self.assertTrue(any(item[1] == "→" for item in res))

    def test_search_copyright(self):
        res = simulate_search(self.data, "copyright")
        self.assertGreater(len(res), 0)
        self.assertEqual(res[0][1], "©")

    def test_search_hex(self):
        res = simulate_search(self.data, "U+00A9")
        self.assertEqual(len(res), 1)
        self.assertEqual(res[0][1], "©")

    def test_search_math_sum(self):
        res = simulate_search(self.data, "math sum")
        self.assertGreater(len(res), 0)
        self.assertTrue(any(item[1] == "∑" for item in res))

if __name__ == "__main__":
    unittest.main()
```

--!nonstrict
-- Unicode Launcher Provider for Noctalia
-- Provides fast searching and one-click copying of ~40,000 Unicode characters.

-- Top-level categories with icons for initial empty query
local CATEGORIES = {
  { id = "category:Arrows", title = "Arrows", subtitle = "Browse arrows (→, ⇒, ➔, ⇡) • Press Enter to view", glyph = "arrow-right" },
  { id = "category:Mathematical Operators", title = "Mathematical Operators", subtitle = "Browse math symbols (∑, √, ∞, ∫, ±) • Press Enter to view", glyph = "math-function" },
  { id = "category:Currency Symbols", title = "Currency Symbols", subtitle = "Browse currencies (€, £, ¥, ₹, ₿) • Press Enter to view", glyph = "currency-dollar" },
  { id = "category:Geometric Shapes", title = "Geometric Shapes", subtitle = "Browse geometric shapes (▲, ■, ◆, ○) • Press Enter to view", glyph = "shapes" },
  { id = "category:Box Drawing", title = "Box Drawing & Blocks", subtitle = "Browse box drawing (─, │, ┌, █, ░) • Press Enter to view", glyph = "border-outer" },
  { id = "category:Dingbats", title = "Dingbats & Symbols", subtitle = "Browse dingbats (★, ✂, ✈, ✔, ✿) • Press Enter to view", glyph = "sparkles" },
  { id = "category:Greek and Coptic", title = "Greek and Coptic", subtitle = "Browse Greek alphabet (α, β, γ, π, Ω) • Press Enter to view", glyph = "letter-case" },
  { id = "category:Letterlike Symbols", title = "Letterlike Symbols", subtitle = "Browse letterlike symbols (№, ℃, ℉, ™) • Press Enter to view", glyph = "typography" },
  { id = "category:General Punctuation", title = "General Punctuation", subtitle = "Browse punctuation (—, …, «, », •) • Press Enter to view", glyph = "quote" },
}

-- Fallback items if data file is missing or corrupt
local FALLBACK_ITEMS = {
  { "00A9", "©", "COPYRIGHT SIGN", "Symbols" },
  { "00AE", "®", "REGISTERED SIGN", "Symbols" },
  { "2122", "™", "TRADE MARK SIGN", "Symbols" },
  { "2190", "←", "LEFTWARDS ARROW", "Arrows" },
  { "2192", "→", "RIGHTWARDS ARROW", "Arrows" },
  { "2191", "↑", "UPWARDS ARROW", "Arrows" },
  { "2193", "↓", "DOWNWARDS ARROW", "Arrows" },
  { "221E", "∞", "INFINITY", "Mathematical Operators" },
  { "221A", "√", "SQUARE ROOT", "Mathematical Operators" },
  { "2248", "≈", "ALMOST EQUAL TO", "Mathematical Operators" },
  { "2260", "≠", "NOT EQUAL TO", "Mathematical Operators" },
  { "2264", "≤", "LESS-THAN OR EQUAL TO", "Mathematical Operators" },
  { "2265", "≥", "GREATER-THAN OR EQUAL TO", "Mathematical Operators" },
  { "20AC", "€", "EURO SIGN", "Currency Symbols" },
  { "00A3", "£", "POUND SIGN", "Currency Symbols" },
  { "00A5", "¥", "YEN SIGN", "Currency Symbols" },
  { "2713", "✓", "CHECK MARK", "Dingbats" },
  { "2714", "✔", "HEAVY CHECK MARK", "Dingbats" },
  { "2717", "✗", "BALLOT X", "Dingbats" },
  { "2718", "✘", "HEAVY BALLOT X", "Dingbats" },
}

local unicodeData = nil
local queryCache = {}
local cacheKeys = {}
local MAX_CACHE_SIZE = 60

local function loadUnicodeData()
  if unicodeData ~= nil then
    return unicodeData
  end

  local content, err = noctalia.readFile("data/unicode.json")
  if not content or err then
    noctalia.notifyError("Unicode", "Failed to load unicode.json: " .. tostring(err))
    unicodeData = FALLBACK_ITEMS
    return unicodeData
  end

  local decoded, jsonErr = noctalia.json.decode(content)
  if not decoded or jsonErr then
    noctalia.notifyError("Unicode", "Failed to parse unicode.json: " .. tostring(jsonErr))
    unicodeData = FALLBACK_ITEMS
    return unicodeData
  end

  unicodeData = decoded
  return unicodeData
end

local function cachePut(query: string, results: { any })
  if #cacheKeys >= MAX_CACHE_SIZE then
    local oldest = table.remove(cacheKeys, 1)
    if oldest then
      queryCache[oldest] = nil
    end
  end
  table.insert(cacheKeys, query)
  queryCache[query] = results
end

local function splitTokens(text: string): { string }
  local tokens = {}
  for token in string.gmatch(text, "%S+") do
    table.insert(tokens, token:upper())
  end
  return tokens
end

local function searchUnicode(query: string, limit: number): { any }
  local cached = queryCache[query]
  if cached then
    return cached
  end

  local data = loadUnicodeData()
  local qUpper = query:upper()
  local isHex = false
  local hexTarget = qUpper

  if string.sub(hexTarget, 1, 2) == "U+" then
    hexTarget = string.sub(hexTarget, 3)
    isHex = true
  elseif #hexTarget >= 2 and string.match(hexTarget, "^[0-9A-F]+$") then
    isHex = true
  end

  local tokens = splitTokens(qUpper)
  local rows = {}
  local count = 0

  for i = 1, #data do
    local item = data[i]
    local code = item[1]
    local char = item[2]
    local name = item[3]
    local cat = item[4]

    local matched = false
    if isHex and string.sub(code, 1, #hexTarget) == hexTarget then
      matched = true
    elseif #tokens > 0 then
      matched = true
      local nameUpper = name:upper()
      local catUpper = cat:upper()
      for t = 1, #tokens do
        local tok = tokens[t]
        if not string.find(nameUpper, tok, 1, true) and not string.find(catUpper, tok, 1, true) then
          matched = false
          break
        end
      end
    end

    if matched then
      count = count + 1
      rows[count] = {
        id = char .. "\t" .. code .. "\t" .. name,
        title = char,
        subtitle = name .. " • " .. cat,
        badge = "U+" .. code,
        glyph = "copy",
      }
      if count >= limit then
        break
      end
    end
  end

  if count == 0 then
    rows[1] = {
      id = "",
      title = "No characters found",
      subtitle = "Try another keyword or hex code (e.g. U+2192)",
      glyph = "mood-empty",
    }
  end

  cachePut(query, rows)
  return rows
end

function onQuery(query: string)
  local trimmed = noctalia.string.trim(query)
  if trimmed == "" then
    launcher.setResults(query, CATEGORIES)
    return
  end

  local maxResults = 30
  local okCfg, cfg = pcall(function()
    return (noctalia.config and noctalia.config.get) and noctalia.config.get() or nil
  end)
  if okCfg and cfg and cfg.max_results then
    maxResults = tonumber(cfg.max_results) or 30
  end

  local results = searchUnicode(trimmed, maxResults)
  launcher.setResults(query, results)
end

function onActivate(id: string)
  if not id or id == "" then
    return
  end

  local category = string.match(id, "^category:(.+)$")
  if category then
    launcher.setQuery(category .. " ")
    return
  end

  local char, code, name = string.match(id, "^([^\t]+)\t([^\t]+)\t([^\t]+)$")
  if not char then
    char = id
    code = ""
    name = ""
  end

  local copyFormat = "character"
  local notifyOnCopy = true

  local okCfg, cfg = pcall(function()
    return (noctalia.config and noctalia.config.get) and noctalia.config.get() or nil
  end)
  if okCfg and cfg then
    if cfg.copy_format then copyFormat = cfg.copy_format end
    if cfg.notify_on_copy ~= nil then notifyOnCopy = cfg.notify_on_copy end
  end

  local textToCopy = char
  if copyFormat == "codepoint" and code ~= "" then
    textToCopy = "U+" .. code
  elseif copyFormat == "both" and code ~= "" then
    textToCopy = char .. " (U+" .. code .. ")"
  end

  local success = noctalia.copyToClipboard(textToCopy, "text/plain")
  if success and notifyOnCopy then
    local detail = if name ~= "" then char .. " (" .. name .. ")" else textToCopy
    noctalia.notify("Unicode", "Copied " .. detail .. " to clipboard")
  elseif not success then
    noctalia.notifyError("Unicode", "Failed to copy to clipboard")
  end
end

# Unicode

Fast Unicode character search and picker. Browse symbols, math, arrows, and copy characters or codepoints instantly.

## Plugin

| Field | Value |
| --- | --- |
| ID | `rigelyon/unicode` |
| Entries | Launcher: `search` |
| Launcher Prefix | `/uni` |

## Usage

Type `/uni` in the Noctalia launcher to browse popular Unicode categories (Arrows, Mathematical Operators, Currency Symbols, Box Drawing, Dingbats, Greek, and more). Selecting a category filters within that set.

To search directly, type `/uni` followed by a character name, keyword, or hex code:

- `/uni arrow right` — finds `→`, `⇒`, `➔`, etc.
- `/uni copyright` — finds `©`
- `/uni infinity` — finds `∞`
- `/uni 00a9` or `/uni U+2192` — finds character by hex codepoint

Press `Enter` or click on any character to copy it to your clipboard.

## Settings

| Setting | Type | Default | Description |
| --- | --- | --- | --- |
| `copy_format` | `select` | `character` | What to copy when activating a result: `character` (`©`), `codepoint` (`U+00A9`), or `both` (`© (U+00A9)`). |
| `notify_on_copy` | `bool` | `true` | Show a desktop toast notification when a character is copied. |
| `max_results` | `int` | `30` | Maximum number of results to display in the launcher (10–100). |

## Notes

- Includes ~40,000 officially named Unicode characters across all Unicode blocks (excluding mass CJK ideographs for optimal search speed and lightweight memory).
- Sub-millisecond search performance with zero startup delay and in-memory memoization.
- Completely local and offline: no external network requests or commands spawned.
```
