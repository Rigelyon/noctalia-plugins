# Pinboard (`rigelyon/pinboard`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build a native Noctalia plugin providing a minimalist, intentional reference stash and an always-on-top pinned screen overlay with dual-mode (Interactive vs Ghost / Click-Through) for artists and gamers.

**Architecture:** A modular Luau architecture for Noctalia Shell. `storage.luau` manages persistent JSON reading/writing and image caching; `state.luau` provides reactive state, layout geometry math, and subscriber dispatching; `components.luau` provides declarative UI widgets; `service.luau` manages IPC commands (`Super+Alt+G` support) and coordinates surfaces; `overlay.luau` drives the Wayland layer-shell surface (`layer = "overlay"`, dynamic `clickThrough`); `panel.luau` manages the stash library, note editor, and controls; and `widget.luau` provides the status bar entry with mode badges and quick gestures.

**Tech Stack:** Luau (Noctalia Plugin API 38, Declarative UI `ui.*`, `noctalia.layer`), Wayland layer-shell, Python 3 + `pytest` / `unittest` (automated test suite).

## Global Constraints
- Target directory: `pinboard/`
- Plugin ID: `rigelyon/pinboard`
- Plugin API version: 38
- License: MIT, Author: rigelyon
- Follow Noctalia design token discipline (`surface`, `primary`, `on_surface`, `outline`, `error`, etc.)
- All Luau files must be non-obfuscated with `--!nonstrict`
- Graceful degradation when running outside Hyprland (use XDG Portal / Zenity / Kdialog fallback for file picking)
- Strict clipboard validation: only process image files, valid URLs, and structured text; reject random unstructured clipboard noise

```python
import json
import os
import tomllib
import unittest

PLUGIN_DIR = os.path.join(os.path.dirname(__file__), "..", "pinboard")


def has_key_path(data, dotted_key):
    cur = data
    for part in dotted_key.split("."):
        if not isinstance(cur, dict) or part not in cur:
            return False
        cur = cur[part]
    return True


class TestPinboardManifest(unittest.TestCase):
    def test_manifest_and_translations(self):
        manifest_path = os.path.join(PLUGIN_DIR, "plugin.toml")
        en_path = os.path.join(PLUGIN_DIR, "translations", "en.json")
        id_path = os.path.join(PLUGIN_DIR, "translations", "id.json")

        self.assertTrue(os.path.isfile(manifest_path), "Missing plugin.toml")
        self.assertTrue(os.path.isfile(en_path), "Missing translations/en.json")
        self.assertTrue(os.path.isfile(id_path), "Missing translations/id.json")

        with open(manifest_path, "rb") as f:
            manifest = tomllib.load(f)
        with open(en_path, "r", encoding="utf-8") as f:
            en = json.load(f)
        with open(id_path, "r", encoding="utf-8") as f:
            id_lang = json.load(f)

        self.assertEqual(manifest.get("id"), "rigelyon/pinboard")
        self.assertEqual(manifest.get("plugin_api"), 38)
        self.assertEqual(manifest.get("author"), "rigelyon")

        # Verify entry declarations
        entries = {
            "widget": False,
            "panel": False,
            "layer": False,
            "service": False,
        }
        if "widget" in manifest:
            entries["widget"] = True
        if "panel" in manifest:
            entries["panel"] = True
        if "layer" in manifest:
            entries["layer"] = True
        if "service" in manifest:
            entries["service"] = True

        for k, v in entries.items():
            self.assertTrue(v, f"Missing [[{k}]] in manifest")

        # Verify all label_key and description_key exist in translations
        for setting in manifest.get("setting", []):
            lk = setting.get("label_key")
            dk = setting.get("description_key")
            if lk:
                self.assertTrue(has_key_path(en, lk), f"en.json missing {lk}")
                self.assertTrue(has_key_path(id_lang, lk), f"id.json missing {lk}")
            if dk:
                self.assertTrue(has_key_path(en, dk), f"en.json missing {dk}")
                self.assertTrue(has_key_path(id_lang, dk), f"id.json missing {dk}")


if __name__ == "__main__":
    unittest.main()
```
