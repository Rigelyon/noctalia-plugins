# NetRadar (`rigelyon/net-radar`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native Noctalia plugin that performs real-time multi-target micro-probing to diagnose network and Wi-Fi quality specifically for online gaming and responsive browsing.

**Architecture:** A lightweight, CPU-budget compliant Luau architecture for Noctalia Shell. `probe.sh` executes a single non-blocking parallel probe (gateway, DNS, game target, and Wi-Fi physical PHY link); `presets.luau` provides regional game server endpoint presets; `state.luau` manages reactive state, in-memory 60-sample circular buffer, RFC 3550 jitter smoothing, 20-sample rolling packet loss, and status classification; `widget.luau` renders a clean icon-only bar widget with dynamic color/glyph and rich hover tooltip; and `panel.luau` renders a Tactical HUD panel with `ui.graph` latency streaming, segmented signal meter, 3-target breakdown cards, and Wi-Fi link health diagnostics.

**Tech Stack:** Luau (Noctalia Plugin API 28, Declarative UI `ui.*`, `barWidget.*`), Bash (`ping`, `ip`, `nmcli`), Python 3 + `pytest` (automated test suite).

## Global Constraints
- Target directory: `net-radar/`
- Plugin ID: `rigelyon/net-radar`
- Plugin API version: 28
- License: MIT, Author: rigelyon
- Follow Noctalia design token discipline (`surface`, `primary`, `on_surface`, `outline`, `destructive`, etc.)
- Strict Luau CPU budget compliance: Single-command probe, adaptive polling (5s idle, 2s active in panel, 10s offline), fixed-size circular buffer, and >= 100ms render throttling
- Default to clean icon-only mode in bar (`show_text_in_bar = false`), no text cluttering the bar by default
- Tactical HUD styling in panel: sharp/4px subtle radius with left accent border and segmented level meter (no rounded pills)
- All Luau files must be non-obfuscated with `--!nonstrict`

```bash
#!/usr/bin/env bash
# NetRadar parallel micro-probe helper
# Target argument: $1 (default: 103.10.124.1 Valve Singapore)
set -u

TARGET="${1:-103.10.124.1}"
GW=$(ip route show default 2>/dev/null | awk '{print $3; exit}')

GW_TMP=$(mktemp)
DNS_TMP=$(mktemp)
GAME_TMP=$(mktemp)

if [ -n "$GW" ]; then
  (ping -c 1 -W 1 "$GW" 2>/dev/null | sed -nE 's/.*time=([0-9.]+) ms/\1/p' > "$GW_TMP") &
else
  echo "none" > "$GW_TMP" &
fi

(ping -c 1 -W 1 "1.1.1.1" 2>/dev/null | sed -nE 's/.*time=([0-9.]+) ms/\1/p' > "$DNS_TMP") &
(ping -c 1 -W 1 "$TARGET" 2>/dev/null | sed -nE 's/.*time=([0-9.]+) ms/\1/p' > "$GAME_TMP") &

# Wi-Fi link information via nmcli
WIFI_RAW=$(nmcli -t -f active,ssid,freq,signal,rate dev wifi 2>/dev/null | grep '^yes:' | head -n 1)

wait

GW_MS=$(cat "$GW_TMP" 2>/dev/null)
DNS_MS=$(cat "$DNS_TMP" 2>/dev/null)
GAME_MS=$(cat "$GAME_TMP" 2>/dev/null)

rm -f "$GW_TMP" "$DNS_TMP" "$GAME_TMP"

[ -z "$GW_MS" ] && GW_MS="none"
[ -z "$DNS_MS" ] && DNS_MS="none"
[ -z "$GAME_MS" ] && GAME_MS="none"

SSID="none"
FREQ="0"
SIGNAL="0"
RATE="0"

if [ -n "$WIFI_RAW" ]; then
  IFS=':' read -r _active _ssid _freq _signal _rate <<< "$WIFI_RAW"
  [ -n "$_ssid" ] && SSID="$_ssid"
  # Extract numeric freq (e.g. "5180 MHz" -> "5180")
  _freq_num=$(echo "$_freq" | tr -dc '0-9')
  [ -n "$_freq_num" ] && FREQ="$_freq_num"
  # Extract numeric signal percentage
  _sig_num=$(echo "$_signal" | tr -dc '0-9')
  [ -n "$_sig_num" ] && SIGNAL="$_sig_num"
  # Extract rate in Mbit/s
  _rate_clean=$(echo "$_rate" | sed -E 's/([0-9.]+).*/\1/')
  [ -n "$_rate_clean" ] && RATE="$_rate_clean"
fi

echo "${GW_MS}|${DNS_MS}|${GAME_MS}|${SSID}|${FREQ}|${SIGNAL}|${RATE}"
```

```python
import math
import unittest


class NetRadarMetricsSimulator:
    def __init__(self, buffer_size=60, loss_window=20):
        self.buffer_size = buffer_size
        self.loss_window = loss_window
        self.history = []  # Ring buffer of float or None
        self.prev_rtt = None
        self.jitter = 0.0
        self.gw_ms = None
        self.dns_ms = None
        self.game_ms = None
        self.loss_pct = 0.0
        self.ssid = ""
        self.freq_mhz = 0
        self.signal_pct = 0
        self.rate_mbps = 0.0

    def process_probe(self, raw_str: str):
        parts = raw_str.strip().split("|")
        if len(parts) < 7:
            return

        self.gw_ms = float(parts[0]) if parts[0] and parts[0] != "none" else None
        self.dns_ms = float(parts[1]) if parts[1] and parts[1] != "none" else None
        self.game_ms = float(parts[2]) if parts[2] and parts[2] != "none" else None
        self.ssid = parts[3] if parts[3] and parts[3] != "none" else ""
        self.freq_mhz = int(parts[4]) if parts[4] and parts[4].isdigit() else 0
        self.signal_pct = int(parts[5]) if parts[5] and parts[5].isdigit() else 0
        self.rate_mbps = float(parts[6]) if parts[6] and parts[6] != "none" else 0.0

        # Update history buffer
        self.history.append(self.game_ms)
        if len(self.history) > self.buffer_size:
            self.history.pop(0)

        # RFC 3550 Jitter: jitter += (abs(rtt - prev_rtt) - jitter) / 16
        if self.game_ms is not None:
            if self.prev_rtt is not None:
                diff = abs(self.game_ms - self.prev_rtt)
                self.jitter += (diff - self.jitter) / 16.0
            self.prev_rtt = self.game_ms

        # Packet loss over last loss_window samples
        window = self.history[-self.loss_window :]
        if window:
            dropped = sum(1 for x in window if x is None)
            self.loss_pct = (dropped / len(window)) * 100.0
        else:
            self.loss_pct = 0.0

    def get_status(self):
        if self.gw_ms is None and self.dns_ms is None:
            return "OFFLINE"
        if self.gw_ms is not None and self.dns_ms is None and self.game_ms is None:
            return "CAPTIVE_PORTAL"
        if self.game_ms is None:
            return "POOR"

        if self.game_ms < 60.0 and self.jitter < 10.0 and self.loss_pct == 0.0:
            return "OPTIMAL"
        if self.game_ms <= 120.0 and self.jitter <= 25.0 and self.loss_pct <= 3.0:
            return "FAIR"
        return "POOR"
```

```luau
--!nonstrict
local presets = require("./presets.luau")

local state = {
  BUFFER_SIZE = 60,
  LOSS_WINDOW = 20,

  -- Current metrics
  gwMs = nil :: number?,
  dnsMs = nil :: number?,
  gameMs = nil :: number?,
  prevGameMs = nil :: number?,
  jitter = 0.0,
  lossPct = 0.0,

  -- Wi-Fi physical PHY link
  ssid = "",
  freqMhz = 0,
  signalPct = 0,
  rateMbps = 0.0,

  -- Active target preset
  activePresetId = "sea_singapore",
  customHost = "1.1.1.1",

  -- Ring buffer for ui.graph (60 samples, nil stored as -1)
  history = {} :: { number },

  -- Subscribers
  listeners = {} :: { () -> () },
  isProbing = false,
  lastProbeTime = 0,
}

for i = 1, state.BUFFER_SIZE do
  table.insert(state.history, -1)
end

function state.subscribe(fn: () -> ())
  table.insert(state.listeners, fn)
end

function state.notify()
  for _, fn in ipairs(state.listeners) do
    fn()
  end
end

function state.getActiveTargetHost(): string
  if state.activePresetId == "custom" then
    return state.customHost ~= "" and state.customHost or "1.1.1.1"
  end
  local p = presets.getById(state.activePresetId)
  return p.host
end

function state.processProbe(rawOutput: string)
  if not rawOutput or rawOutput == "" then
    return
  end

  local parts = {}
  for part in string.gmatch(rawOutput, "([^|]+)") do
    table.insert(parts, part)
  end

  if #parts < 7 then
    return
  end

  state.gwMs = (parts[1] ~= "none") and tonumber(parts[1]) or nil
  state.dnsMs = (parts[2] ~= "none") and tonumber(parts[2]) or nil
  state.gameMs = (parts[3] ~= "none") and tonumber(parts[3]) or nil
  state.ssid = (parts[4] ~= "none") and parts[4] or ""
  state.freqMhz = tonumber(parts[5]) or 0
  state.signalPct = tonumber(parts[6]) or 0
  state.rateMbps = tonumber(parts[7]) or 0.0

  -- Push into fixed ring buffer
  table.remove(state.history, 1)
  table.insert(state.history, state.gameMs or -1)

  -- RFC 3550 Jitter
  if state.gameMs then
    if state.prevGameMs then
      local diff = math.abs(state.gameMs - state.prevGameMs)
      state.jitter = state.jitter + (diff - state.jitter) / 16.0
    end
    state.prevGameMs = state.gameMs
  end

  -- Packet loss over rolling window
  local dropped = 0
  local total = 0
  local startIndex = math.max(1, state.BUFFER_SIZE - state.LOSS_WINDOW + 1)
  for i = startIndex, state.BUFFER_SIZE do
    total = total + 1
    if state.history[i] < 0 then
      dropped = dropped + 1
    end
  end
  state.lossPct = total > 0 and (dropped / total) * 100.0 or 0.0

  state.notify()
end

function state.getStatus(): string
  if not state.gwMs and not state.dnsMs then
    return "OFFLINE"
  end
  if state.gwMs and not state.dnsMs and not state.gameMs then
    return "CAPTIVE_PORTAL"
  end
  if not state.gameMs then
    return "POOR"
  end

  if state.gameMs < 60.0 and state.jitter < 10.0 and state.lossPct == 0.0 then
    return "OPTIMAL"
  end
  if state.gameMs <= 120.0 and state.jitter <= 25.0 and state.lossPct <= 3.0 then
    return "FAIR"
  end
  return "POOR"
end

function state.getGraphValues(): ({ number }, number, number, number)
  local values = {}
  local minMs = 999999.0
  local maxMs = 0.0
  local sumMs = 0.0
  local count = 0

  for i = 1, state.BUFFER_SIZE do
    local v = state.history[i]
    if v >= 0 then
      if v < minMs then minMs = v end
      if v > maxMs then maxMs = v end
      sumMs = sumMs + v
      count = count + 1
    end
  end

  local ceiling = math.max(100.0, maxMs * 1.25)
  for i = 1, state.BUFFER_SIZE do
    local v = state.history[i]
    if v < 0 then
      table.insert(values, 0.0)
    else
      table.insert(values, math.min(1.0, math.max(0.0, v / ceiling)))
    end
  end

  local avgMs = count > 0 and (sumMs / count) or 0.0
  if minMs > 999990.0 then minMs = 0.0 end

  return values, minMs, avgMs, maxMs
end

return state
```

```luau
local function throttledRender()
  local now = (noctalia and noctalia.nowMs) and noctalia.nowMs() or (os.clock() * 1000)
  if now - lastRenderTime < 100 then
    return
  end
  lastRenderTime = now
  if render then
    render(renderPanel())
  end
end

state.subscribe(function()
  throttledRender()
end)

function update(deltaMs: number)
  local now = (noctalia and noctalia.nowMs) and noctalia.nowMs() or (os.clock() * 1000)
  local activeInterval = 2000
  if noctalia and noctalia.getConfig then
    local cfg = noctalia.getConfig("active_poll_interval_sec")
    if type(cfg) == "number" and cfg >= 1 then
      activeInterval = cfg * 1000
    end
  end

  if now - activePollTimer >= activeInterval then
    activePollTimer = now
    executeProbe()
  end
end
```

```markdown
# NetRadar (`rigelyon/net-radar`)

<p align="center">
  <strong>Real-time multi-target network radar & gaming latency diagnostics with Wi-Fi physical link health for Noctalia Shell.</strong>
</p>

---

## Why NetRadar?

Have you ever connected to a Wi-Fi network that shows full signal bars ("Connected"), only to find that opening a match in your favorite game causes severe stutter, rubberbanding, or packet loss? 

Standard network monitors only report current throughput (KB/s), and speed tests consume valuable mobile data. **NetRadar** solves this by continuously sending lightweight micro-probes (~64 bytes) to test:
1. **Local Wi-Fi Gateway**: Detects if high latency or packet loss is caused by local router interference (especially on 2.4 GHz channels).
2. **Public Internet DNS (`1.1.1.1`)**: Verifies general internet uptime and catches captive portals.
3. **Regional Game Server Clusters**: Measures real-world competitive gaming RTT, Jitter (RFC 3550), and Packet Loss %.

---

## Features

- **Icon-Only by Default**: Designed to keep your Noctalia status bar clean. Displays a single dynamic icon glyph that reflects connection readiness (`primary` for Game-Ready, `warning` for casual only, `destructive` for lag/packet loss).
- **Tactical HUD Telemetry Panel**: Sharp, minimal dashboard with segmented signal level meter, real-time streaming `ui.graph` (60s history), 3-target breakdown, and Wi-Fi PHY diagnostics (SSID, 2.4/5GHz band, signal dBm, link speed).
- **Strict CPU Budget Compliance**:
  - Combined single-command micro-probe (`probe.sh`).
  - Adaptive polling (5s background, 2s active in panel, 10s backoff when offline).
  - Pre-allocated 60-sample ring buffer to prevent GC churn.
  - Render throttling (>= 100ms) to prevent Luau instruction budget exhaustion.
- **Bilingual Support**: Full English and Indonesian localization out of the box.

---

## External Dependencies

NetRadar uses standard Linux networking utilities:
- `iputils` (`/usr/bin/ping`)
- `iproute2` (`/usr/bin/ip`)
- `networkmanager` (`/usr/bin/nmcli`)
```
